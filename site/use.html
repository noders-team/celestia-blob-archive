Read API

The API answers celestia-node’s JSON-RPC for blob.Get, blob.GetAll, blob.GetProof, blob.Included and header.GetByHeight, with the same JSON a node returns. Point a client that already talks to a node at it.

What the errors mean

blob: not found comes back only when the archive holds the height and that blob is not in it, so a client can treat it as final. A height the archive has not reached yet, or an upstream problem, gets a different message that never contains “not found”, so op-alt-da and ev-node retry or ask another source. A blob withdrawn on legal request gets its own error pointing at tombstones.json.

Before serving a blob the API re-checks its share proof against the block’s stored data root. Limits: 16 calls per batch, 16 namespaces per GetAll, 20 requests per second per client. No WebSocket, so no Subscribe.

OP Stack rollups: the op-alt-da fallback

For OP Stack rollups that post to Celestia, the archive also writes each blob under the key op-alt-da’s S3 fallback reads. Add these flags to your da-server and it re-derives from the archive once Celestia has pruned the data.

Verify and export with cba

Build it from the repository with make build. cba verify reads the archive directly, takes the data root from a node you trust and checks the blob’s share proof under it. That is the check that does not depend on NODERS.

cba export writes every blob of a namespace in a height range to files. It checks each blob against the archive’s own records; use cba verify when you need proof of inclusion.

For a captured Fibre payload, cba fibre verify rederives the blob ID from the payment promise, checks the promise’s signature and re-encodes the payload to the paid commitment.

Raw files

The archive is plain objects over HTTPS. manifest.json says how far it reaches, dir/ maps every height to its rows, each segment’s .idx2 lists the namespace and commitment of every blob, and the .seg holds the records with their proofs. Finding one blob takes four range requests; the block page on this site does exactly that.
